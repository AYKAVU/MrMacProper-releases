# MrMacProper — загрузки

Здесь лежат готовые сборки **MrMacProper** для macOS. Исходный код в этом репозитории не хранится.

MrMacProper следит за памятью и диском и чистит кэши — без подписки и без телеметрии.

## Скачать

Последняя версия — на вкладке [Releases](../../releases/latest).

Прямая ссылка на свежий файл:
`https://github.com/AYKAVU/MrMacProper-releases/releases/latest/download/MrMacProper-1.1.dmg`

## Установка

1. Открыть скачанный `.dmg` и перетащить **MrMacProper** в «Программы».
2. При первом запуске — **правая кнопка по значку → «Открыть»**, затем ещё раз «Открыть» в диалоге.

Второй шаг нужен потому, что приложение не подписано сертификатом Apple Developer: обычный
двойной клик macOS заблокирует и скажет «повреждено». После первого запуска через «Открыть»
система запомнит выбор.

Если файл пришёл через мессенджер и macOS всё равно ругается — снять карантин:

```
xattr -cr /Applications/MrMacProper.app
```

## Что делает

- **Обзор** — диск и память, сколько мусора можно убрать.
- **Мониторинг системы** — что за машина и в каком она состоянии: чип и ядра,
  видеоядро, ОЗУ, накопитель и FileVault, батарея с износом и циклами,
  тепловое состояние, сколько работает без перезагрузки.
- **Мусор** — кэши приложений и разработчика с объяснением последствий по каждому
  пункту. По «Развернуть полную информацию» видно, что именно программа там хранит,
  какие папки уедут в Корзину и какие файлы лежат внутри.
- **Большие файлы** — что занимает место в домашней папке и что давно не открывалось.
- **Память** — из чего складывается занятая память и кто её держит. Процесс можно
  завершить, но только через подтверждение.
- **Менюбар** — память, диск, процессор одним взглядом.

## Чем отличается от подобных программ

Не врёт ради красивых цифр:

- **Нет кнопки «освободить память».** В macOS она ничего не чинит — система сама решает,
  что держать в памяти. Вместо неё показан список процессов, которые её держат.
- **Purgeable показан отдельно.** `df` и Finder дают разные числа свободного места;
  разница — это снапшоты и кэши, которые система освободит сама. Показаны оба числа.
- **Если чистить нечего — так и написано.**

## Безопасность

- Удаление только в **Корзину**. Вернуть можно в любой момент.
- Чистится только то, что описано правилом. Никаких эвристик «просканируем и решим на месте».
- Ни одно правило не выходит за пределы домашней папки. `Documents`, `Desktop`, `Downloads`,
  `Pictures`, `Movies`, `Music`, `.ssh`, `.gnupg` защищены отдельно.
- По умолчанию отмечено только то, что восстановится само.
- Перед удалением можно раскрыть и посмотреть точный список путей и файлов.
- Кэш запущенной программы не трогается — приложение предупредит и пропустит его.

О железе читаются только характеристики и состояние. Серийный номер, UUID, имя
пользователя и имя компьютера не собираются. Сети у приложения нет вообще.

## Требования

macOS 14 (Sonoma) или новее. Apple Silicon.
